How to use this

Assignment logic for the PM

The PM should not invent the batch. Pull from this library, assign by format, and move each concept into briefing.

UGC

Use when you want message control

  • Clear hook
  • Specific talking points
  • Better angle testing
CGC

Use when you want discovery energy

  • Feels more human
  • Better for gifting and skeptical-friend angles
  • Less polished, more believable
Design / Edit

Use when you need speed and repeatability

  • Statics for fast testing
  • Carousels for explanation
  • Edits for using existing footage
